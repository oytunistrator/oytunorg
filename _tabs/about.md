## Profile

I am a technology leader and senior full-stack software developer with more than 12 years of experience building web applications and software products. My work has included backend and frontend development, APIs, data systems, cloud delivery, and team coordination. I currently manage projects for [OnixOS](https://onix-project.com/) and continue to build independent software and web projects.

## Selected projects

### Systems and developer tools

- [OnixOS](https://onix-project.com/): An open-source, Arch-based Linux distribution with developer-focused tools.
- [O Language](https://onix-project.com/O_Language): A system-oriented functional programming language developed as part of the OnixOS ecosystem.
- [ODesk](https://gitlab.com/onix-os/applications/odesk): A desktop environment project for OnixOS.
- [OpenXenManager](https://github.com/oytunistrator/openxenmanager-xcpng): A graphical interface for managing XCP-ng hosts over a network.
- [Kasm Registry](https://oytunistrator.github.io/oytunistrator-kasm-registry/1.0/): A registry of custom application images for Kasm Workspaces.
- [ProjectQ-Docker](https://gitlab.com/oytunistrator/projectq-docker): A Docker-based ProjectQ quantum simulation setup with a Jupyter server and a mounted notebooks folder.
- [php-dirlister](https://github.com/oytunistrator/php-dirlister): A lightweight PHP directory listing script.

### Web products and experiments

- [Tedaryum](https://tedaryum.com/): An interactive browser game and playful web project built around the "Kaşarı Vur" arcade concept.
- [Gürültü Dedektifi](https://gurultudedektifi.com/): A community-powered urban noise mapping and reporting platform.
- [NoiseMap](https://noise.odznames.com/): A public map for exploring reported urban noise.
- [AquaLLM](https://huggingface.co/oytunistrator/AquaLLM): A language model fine-tuned to answer questions about aquarium care, equipment, water parameters, fish, and aquatic plants.
- [Odznames Tools](https://tools.odznames.com/): A collection of web utilities, including [Cloudflare Finder](https://tools.odznames.com/cff/) and [Network Tools](https://tools.odznames.com/ntools/).
- [PwgenTR](https://pwgentr.odznames.com/): A password and cryptography utility.
- [Son Depremler](https://deprem.odznames.com/index.html): An earthquake information page.
- [Oytun.org](https://oytun.org/): My personal site and engineering blog.

See the [full project list on LinkedIn](https://www.linkedin.com/in/oytunistrator/details/projects/) for additional work, including smaller web tools and publications.
